# Jade Clinic 3D 🩺

ภาษาจีน → พินอิน → ไทย → English มีสวิตช์เปิด–ปิดพินอินและคำแปลไทยแยกกันระหว่างเล่นได้

## เปิดเล่นเร็วที่สุด

- **บนคอมพิวเตอร์:** เปิด `PLAY.html` ด้วย Chrome, Edge, Firefox หรือ Safari เป็นไฟล์หน้าเดียว ไม่ต้องติดตั้งโปรแกรมหรือดาวน์โหลดไลบรารี
- **บน iPad / iPhone:** แนะนำเปิดผ่านลิงก์ GitHub Pages ใน Safari ตามขั้นตอนด้านล่าง แอป Files หรือหน้าพรีวิวเอกสารบางแอปไม่รัน JavaScript จากไฟล์ HTML
- **สำหรับแก้โค้ด:** เปิด `index.html` ที่อยู่คู่กับโฟลเดอร์ `src/` และ `assets/` หรือใช้ static web server ของคุณ

ไม่มี API key ไม่มีฐานข้อมูล และไม่ต้องตั้งค่า Supabase

## นำขึ้น GitHub Pages แบบไม่ต้องเขียนโค้ด

1. สร้าง repository ใหม่ใน GitHub ชื่อใดก็ได้
2. แตกไฟล์ ZIP นี้ก่อน แล้วใช้ **Add file → Upload files** อัปโหลดไฟล์และโฟลเดอร์ **ภายใน** `jade-clinic-3d/` ลง repository
3. ตรวจว่า `index.html`, `src/`, `assets/` อยู่ที่ระดับแรกของ repository อย่าอัปโหลด ZIP ทั้งก้อน และอย่าให้ `index.html` ซ้อนอยู่ในโฟลเดอร์อีกชั้น
4. Commit ไฟล์ แล้วไป **Settings → Pages**
5. ใน **Build and deployment** เลือก **Source: Deploy from a branch**, **Branch: main**, โฟลเดอร์ **/(root)** แล้วกด Save
6. รอ GitHub ประมวลผล แล้วเปิดลิงก์ที่แสดงในหน้าตั้งค่า Pages ด้วย Safari หรือ Chrome

เกมใช้เส้นทางไฟล์แบบ relative จึงใช้ได้ทั้ง repository ปกติและเว็บไซต์ระดับบัญชี หากบัญชีของคุณจำกัด Pages สำหรับ repository ส่วนตัว ให้ใช้ repository ที่รองรับ Pages ตามสิทธิ์บัญชีของคุณ

เอกสาร GitHub: <https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site>

## วิธีเล่นและคะแนน

ลำดับแต่ละเคส: เปิดการสนทนา → ระยะเวลา → ลักษณะอาการ → ปัจจัยกระตุ้น → อาการร่วม → ลิ้น → ชีพจร → วินิจฉัยกลุ่มอาการ

- เริ่ม **100 คะแนน**
- เลือกคำถามไม่ตรงเป้าหมายของขั้นนั้น: **−8**
- วินิจฉัยผิด: **−15**
- ขอคำใบ้: **−5** ใช้ได้หนึ่งครั้งต่อขั้น
- คะแนนต่ำสุด **0** ยังตอบต่อได้ ไม่มีเกมโอเวอร์หรือล็อกค้าง ต้องตอบถูกก่อนจึงผ่านขั้น/เคส
- ปุ่มตัวเลือกที่ผิดจะถูกปิด ไม่หักซ้ำเมื่อกดซ้ำ
- 3 ดาว: คะแนน ≥90 และไม่ใช้คำใบ้; 2 ดาว: คะแนน ≥65; อื่น ๆ: 1 ดาว
- การเล่นซ้ำเก็บคะแนนดีที่สุด ไม่เพิ่มคะแนนสะสมซ้ำโดยไม่พัฒนาสถิติ
- ถ้าผ่านโดยมีข้อผิดพลาดหรือใช้คำใบ้ จะเพิ่มกลุ่มนั้นในรายการฝึกซ้ำ ผ่านแบบไม่ผิดและไม่ใช้คำใบ้เพื่อล้างจุดพลาดของกลุ่มนั้น

**ความหมายของคำถามผิด:** เกมเป็นแบบฝึกเลือกคำถามตามเป้าหมายที่แสดงบนการ์ด คำถามอื่นบางข้ออาจเหมาะสมในประวัติเต็ม แต่ยังไม่ตอบเป้าหมายของรอบนั้น ไม่ได้หมายความว่าเป็นคำถามที่ผิดทางการแพทย์เสมอไป

ไฟล์ `CASE-COVERAGE.json` มีรายการทุกกลุ่ม ทุกชื่อ และรหัสเคสเพื่อเช็กความครบถ้วน

## ข้อจำกัดเนื้อหาที่มีผลต่อการเรียน

- นี่คือการฝึก **证型 · zhèngxíng · กลุ่มอาการ · TCM pattern** ตามกรอบเอกสาร ไม่ใช่การวินิจฉัยโรคสมัยใหม่
- อาการที่พบบ่อยไม่จำเป็นต้องมีครบทุกข้อ และไม่มีอาการเดี่ยว ลิ้น หรือชีพจรใดใช้ยืนยันได้เพียงอย่างเดียว
- กรณี **黄汗 · huánghàn · เหงื่อเหลือง · yellow sweating** จัดตามแบบฝึกชื้นร้อนที่ผู้เรียนส่งมา ตำราคลาสสิกอาจจำแนกต่างกัน คราบเสื้อเหลืองมีหลายสาเหตุ
- **肝肾不足 · gānshèn bùzú · ตับไตพร่อง · Liver–Kidney deficiency:** เสียงในหูค่อนข้างเบาไม่เท่ากับเสียงทุ้ม จึงแก้การใช้คำอังกฤษ `low-pitched` ในข้อความเดิมเป็น `faint`
- แบบแห้งรุกรานปอดมีทั้งแห้งร่วมร้อนและแห้งร่วมเย็น ชีพจรจึงอาจต่างกัน ไม่บังคับค่าหนึ่งค่าในทุกกรณี
- อาการเจ็บหน้าอกเฉียบพลัน หายใจผิดปกติรุนแรง หรือการได้ยินลดฉับพลันต้องประเมินความเร่งด่วนในคนไข้จริง เกมไม่ใช้ตัดสินความปลอดภัยหรือวางแผนรักษา และไม่ให้คำแนะนำเรื่องยา
- ตัวละคร 3D เป็นภาพประกอบ ให้อ่านผลลิ้นและชีพจรที่เขียนในแฟ้ม ไม่ใช้สีหรือหน้าตาของตัวละครแทนผลตรวจ

แหล่งคำศัพท์เพิ่มเติม: WHO, *WHO international standard terminologies on traditional Chinese medicine*, 2022, <https://www.who.int/publications/i/item/9789240042322> ใช้เป็นเอกสารคำศัพท์เพิ่มเติม ไม่ใช่การรับรองเคสหรือเกม

## เสียงและการบันทึก

เสียงอ่านใช้ `speechSynthesis` และเสียงจีนที่มีในอุปกรณ์ ไม่ส่งข้อความไปยังบริการ AI ภายนอก หากไม่มีเสียงจีน เกมจะแจ้งให้ทราบ บางเสียงอาจขึ้นกับเครือข่ายและการตั้งค่าของระบบปฏิบัติการ

คะแนนและสวิตช์ภาษาบันทึกด้วย `localStorage` บนเบราว์เซอร์นั้น ไม่มีบัญชีหรือเซิร์ฟเวอร์เก็บข้อมูล หากเปลี่ยนอุปกรณ์ เปลี่ยนโดเมน เปิดไฟล์คนละตำแหน่ง หรือล้างข้อมูลเว็บ ความคืบหน้าอาจแยกหรือหายได้ ใช้ปุ่มส่งออก/นำเข้าในหน้าพัฒนาการเพื่อย้ายข้อมูล

## สำหรับผู้พัฒนา

ใช้ HTML / CSS / JavaScript และ WebGL โดยตรง ไม่มี runtime dependencies และไม่มี CDN ฉากคลินิก ตัวละคร วัสดุ และแอนิเมชันสร้างจากโค้ดทั้งหมด หาก WebGL ไม่พร้อมจะใช้ renderer 3D แบบ CPU พร้อม depth buffer บน Canvas 2D กับโมเดลชุดเดียวกัน โหมดสำรองวาดใหม่เมื่อหมุนกล้องหรือมีการโต้ตอบเพื่อลดการใช้แบตเตอรี่ แอนิเมชันต่อเนื่องใช้ WebGL คุณภาพและความลื่นอาจต่างกัน

```text
jade-clinic-3d/
  index.html              จุดเข้าเว็บแบบหลายไฟล์ / GitHub Pages root
  PLAY.html               เกมหน้าเดียว รวมโค้ดและสไตล์ ใช้ทดลองแบบออฟไลน์
  src/data.js             เนื้อหา จีน พินอิน ไทย อังกฤษ
  src/engine.js           สร้างเคส กติกาคะแนน ล็อกขั้น และเหตุผลวินิจฉัย
  src/scene.js            ฉาก ตัวละคร กล้อง WebGL และ CPU renderer
  src/app.js              UI ห้องทบทวน คลังเคส ความคืบหน้า
  src/styles.css         รูปแบบและ responsive layout
  assets/icon.svg        ไอคอนที่สร้างด้วยโค้ด
  tests/                 ทดสอบทุกเคสและ renderer
  tools/build.cjs        รวม PLAY.html และเตรียม dist/
  dist/                  เว็บไซต์ที่จัดไว้สำหรับนำไปใช้
  CASE-COVERAGE.json     ตารางความครอบคลุมทุกเคส
```

หากแก้ไฟล์ใน `src/` ให้เปิดผ่าน `index.html` เพื่อพัฒนา แล้วรัน build เพื่ออัปเดต `PLAY.html` และ `dist/`:

```bash
npm test
npm run build
```

ต้องมี Node.js 18 ขึ้นไป ไม่ต้องรัน `npm install` มี workflow CI สำหรับรันทดสอบและ build เมื่อ push โค้ด การเผยแพร่แบบง่ายใช้ Pages จาก `main` / `(root)` ตามคู่มือด้านบน

## English overview

A self-contained 3D TCM interview learning game with 16 complaint groups, 65 curriculum entries, 56 distinct pattern names, and 195 fictional case variants. Each case requires seven interview/examination steps before pattern selection. Wrong questions and diagnoses deduct points and must be retried; a zero score never blocks learning. Study, comparison, flashcards, vocabulary, targeted practice, progress export/import, independent Pinyin and Thai toggles, and optional Chinese device speech are included. Educational simulation only; no patient treatment decisions.
